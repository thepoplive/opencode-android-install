# OpenCode на Android (Termux)

Это руководство поможет установить и запустить [OpenCode](https://github.com/anomalyco/opencode) — открытого AI-агента для работы с кодом — прямо на Android через [Termux](https://termux.dev/). Используется сторонняя сборка для Android/Bionic из проекта [bd-loser/opencode-bionic](https://github.com/bd-loser/opencode-bionic).

> **Неофициальная сборка сообщества.** Это не официальный дистрибутив OpenCode или Termux. Перед запуском проверьте проект и установщик. Команда ниже скачивает и выполняет скрипт из интернета.

> **Проверено:** владелец репозитория подтвердил, что команда установки работает на реальном Android-устройстве с Termux. Результаты могут отличаться в зависимости от устройства; при сообщении о проблеме укажите модель устройства, версию Android и данные Termux.

## Требования

- Android-устройство с поддерживаемой версией Android.
- Termux из надёжного источника. Команды рассчитаны на обычный Termux с менеджером пакетов `pkg` / `apt`.
- Архитектура **ARM64 / aarch64**. Сборка Bionic не предназначена для 32-битного ARM или x86 Android.
- Интернет и свободное место в памяти.

Проверить архитектуру:

```sh
uname -m
```

Ожидаемый результат: `aarch64`.

## Установка

Обновите пакеты Termux и установите утилиты для загрузки:

```sh
pkg update && pkg upgrade -y
pkg install curl ca-certificates -y
```

Установите последнюю стабильную сборку для Android/Bionic:

```sh
curl -fsSL https://raw.githubusercontent.com/bd-loser/opencode-bionic/main/install.sh | bash
```

Согласно документации проекта, установщик скачивает последний стабильный ARM64-пакет `.deb`, проверяет его контрольную сумму SHA-256 и устанавливает через `dpkg`.

Проверьте версию и запустите OpenCode:

```sh
opencode --version
opencode
```

## Первый запуск и авторизация

OpenCode — это агент для работы с кодом, а не самостоятельная языковая модель. Вам понадобится доступ к поддерживаемому провайдеру моделей.

В интерактивном терминале Termux выполните:

```sh
opencode auth login
```

Посмотреть настроенных провайдеров можно командой:

```sh
opencode auth list
```

Перейдите в папку проекта и запустите OpenCode в ней:

```sh
cd ~/my-project
opencode
```

Замените `~/my-project` на реальный путь к проекту. Чтобы работать с общей памятью Android, сначала выполните `termux-setup-storage` и подтвердите запрошенные разрешения Android.

Установщик также позволяет выбрать сборку. Эти параметры необязательны; используйте их, только если нужна предварительная или конкретная версия. Актуальные варианты смотрите в [документации исходного проекта](https://github.com/bd-loser/opencode-bionic#install).

## Обновление или повторная установка

Повторно запустите установщик — он установит последнюю стабильную сборку:

```sh
curl -fsSL https://raw.githubusercontent.com/bd-loser/opencode-bionic/main/install.sh | bash
```

## Решение проблем

### Ошибка `404` при установке

Проверьте URL и доступность GitHub. Не добавляйте ссылку на GitHub Releases как APT-репозиторий: страница загрузки релизов не является индексом пакетов APT.

### `Unable to locate package opencode`

В этом руководстве OpenCode не устанавливается из стандартного APT-репозитория Termux. Используйте команду установщика выше, а не `pkg install opencode`.

### `Pointer tag ... was truncated`, затем `Aborted`

Это может указывать на несовместимость нативного бинарника или runtime. Простая смена APT-зеркала не обязательно решит проблему. Повторно запустите установщик, чтобы получить актуальную стабильную сборку:

```sh
curl -fsSL https://raw.githubusercontent.com/bd-loser/opencode-bionic/main/install.sh | bash
opencode --version
opencode
```

Если приложение продолжает аварийно завершаться, приложите полный вывод ошибки в [Issues проекта bd-loser/opencode-bionic](https://github.com/bd-loser/opencode-bionic/issues). Укажите версию Android, архитектуру (`uname -m`), версию Termux (`termux-info`) и точную команду запуска. Не публикуйте API-ключи и токены авторизации.

### `opencode: runtime not found` или ошибки установки пакета

Повторно запустите установщик и сохраните полный текст ошибки. Проверьте свободное место и убедитесь, что менеджер пакетов Termux не остался в состоянии незавершённой установки. Не перемещайте вручную случайные runtime-библиотеки и не устанавливайте посторонние бинарники.

### Удаление ошибочного источника, добавленного при предыдущей попытке

Удаляйте этот файл **только если вы создали его по прежней инструкции, где GitHub Releases был указан как APT-репозиторий**:

```sh
rm -f "$PREFIX/etc/apt/sources.list.d/hope2333.list"
pkg update
```

Это не удаляет OpenCode. Не удаляйте другие файлы источников, если не знаете, для чего они нужны.

## Безопасность

- Команда установщика выполняет удалённый shell-скрипт. Перед запуском можно прочитать [install.sh](https://github.com/bd-loser/opencode-bionic/blob/main/install.sh).
- Используйте только ссылку на исходный проект, указанную в этом руководстве; остерегайтесь похожих репозиториев и скопированных команд.
- Никогда не публикуйте API-ключи, пароли или приватные токены в открытых Issues.
